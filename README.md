# Agro Forte, Futuro Sustentável

Projeto desenvolvido em p5.js para demonstrar o uso da energia solar na irrigação agrícola.

## Cenas

1. Falta de irrigação
2. Solução com energia solar
3. Futuro sustentável

## Tecnologias

- JavaScript
- p5.js

## Como executar

Abra o arquivo `index.html` em um navegador ou publique no GitHub Pages.
